# Move Along visual direction

Owner-selected UI: 8bitcn/ui, installed with the official shadcn registry.
Palette: ink #222039, paper #f7f5ff, violet #7152d6, mint #c9edb0,
peach #ffd9c0, muted ink #68647b. Colors live in semantic CSS tokens.
Type: Press Start 2P for display and short labels, Geist for readable body text.
Layout: quiet navigation, a wide title/intro beside an original pixel movement
scene, then a compact routine selection with distinct illustrations.
Portrait stacks content, keeps buttons large, and avoids cropping text.

The memorable element is the pixel movement stage with three exercise poses.
8bitcn borders/buttons connect the illustration to the interface. Avoid an
unrelated RPG inventory, health meters, pressure/streaks or dense game decoration.
No flashing effects. Respect reduced motion. Instructions use sentence case.

Phase 1 covers navigable preview shells; camera, inference, scoring and clocks
are explicitly deferred to their own gates.
