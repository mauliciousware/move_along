# Self-hosted tracking assets

Generated by `npm run setup:mediapipe` from the pinned @mediapipe/tasks-vision
package, with Google's version-1 float16 pose_landmarker_lite model.

Only local URLs are used at runtime. Model download happens during setup, never
from a user's camera session. The script checks the pinned model SHA-256 and
writes an asset manifest. Keep these assets and the model available in deployments.

Upstream source: https://github.com/google-ai-edge/mediapipe
